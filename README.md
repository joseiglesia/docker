# Aplicación Cliente-Servidor con Docker

Proyecto académico desarrollado para implementar una arquitectura cliente-servidor utilizando Docker.

## Tecnologías utilizadas

- Docker
- Docker Compose
- Node.js
- JavaScript

## Estructura del proyecto

├── Client
├── Server
├── docker-compose.yml
├── .env

## Funcionalidades

- Comunicación entre cliente y servidor.
- Contenerización mediante Docker.
- Configuración automatizada con Docker Compose.
